This portfolio is built as a single, self-contained, high-performance web experience adhering to a **Neo-Skeuomorphic / Soft-Glassmorphic SaaS aesthetic**.

### Running Locally
You can view the portfolio directly by opening `index.html` in any modern web browser, or launch a local server:

```bash
# Using Python
python -m http.server 3000

# Using Node.js / npx
npx serve .
```
Then navigate to `http://localhost:3000` in your browser.
